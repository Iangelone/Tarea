# Guía para agentes

## Idea del proyecto

Construir una aplicación que combine un **clasificador de reclamos o tickets de soporte por prioridad y categoría** con un **chat sobre documentos (RAG) de una empresa ficticia**. 

## Convención de commits

- Crear un commit por cada cambio lógico y completo; revisar el diff y las verificaciones pertinentes antes de hacerlo.
- Usar `tipo(alcance): descripción`, con alcance opcional y descripción breve en español.
- Tipos comunes: `feat`, `fix`, `docs`, `refactor`, `test` y `chore`.
