# Soporte técnico

## Reportar un error

Para investigar un error, soporte solicita una descripción del problema, la hora aproximada, los pasos para reproducirlo y el mensaje de error, si aparece. El cliente no debe enviar contraseñas ni datos sensibles.

## El problema afecta a una persona

Si el error afecta a una sola persona, soporte debe comprobar si puede reproducirlo y recomendar cerrar y volver a abrir la aplicación. Si continúa, debe derivar el caso al equipo técnico con la información recopilada.

## El servicio no funciona para todos

Si todos los usuarios están afectados y no pueden utilizar la plataforma, soporte debe registrar un incidente crítico y avisar de inmediato al equipo técnico de guardia.

## Seguimiento de incidentes

El equipo técnico comunica el estado del incidente a soporte. Soporte informa al cliente cuando hay novedades verificadas y confirma con él si el problema quedó resuelto antes de cerrar el ticket.
